# 牌桌教練 v2.2
台灣 16 張的單機教練練習。仍採下列簡化桌規，並非完整比賽規則。

## 開啟
在本資料夾執行 `python -m http.server 4176 --bind 127.0.0.1`，開啟 http://localhost:4176 。
右上角顯示「教練練習 v2.2」。

## v2.2 更新：用動作看出摸切、手切、空切；隨時整理手牌
- 出牌改成從牌實際所在的位置飛進牌河，不再用文字標示：
  - 摸切：剛摸進、放在最右邊隔開的那張直接丟出，其他牌不動。
  - 手切：從牌列中間先抽起一張再飛出，後面的牌補位，剛摸的那張滑進手牌。
  - 空切：看起來和手切一樣（這正是空切的用意）。
- 四家都一樣：電腦摸牌時，新牌從上方落在牌架最右邊並隔開，接著出牌就看得出是摸切還是手切（左右兩家的牌架依旋轉方向換算動作）。
- 拿掉牌河的「摸／空」字樣、圖例與座位上的「連續摸切」文字；讀牌筆記仍會整理訊號。灰底輔助標示改為 ⚙ 選項、預設關閉。
- 電腦每步間隔放慢到 0.7 秒，看得清楚動作；系統開啟「減少動態效果」時不播動畫。
- 「整理手牌」隨時都能按（別人出牌、吃碰回應時也可以），排序有滑動動畫；剛摸進還沒打的那張仍留在最右邊。

## v2.1 更新：摸切／手切、過水、保留八墩、讀牌與口訣
參考網路上的台灣麻將教學（見文末「參考資料」），比對後補上下列規則與教練觀念：
- 摸切／手切／空切：引擎記錄每張出牌方式（v2.2 起改用出牌動作呈現）。自己剛摸進的牌放在最右邊、上方標「摸」，「整理手牌」不會把它排進去。點最右邊那張是摸切；點手中另一張相同的牌就是空切（別人看起來是手切，只有你自己的牌河標「空」）。電腦要打剛摸進的牌時一律摸切。
- 讀牌：各家名牌顯示「連續摸切 N」；教練欄新增「讀牌筆記」，依攤牌、連續摸切、最近手切的牌、一直打哪門、攤牌是否全同一花色（清一色／混一色訊號）整理三家的訊號。高級電腦與危險度也使用這些訊號：連續摸切三巡以上視為可能聽牌、四巡以上視為很可能聽牌；攤牌全同一花色時，該門與字牌危險度加倍。
- 過水（預設開啟）：放過胡牌後，在自己打出一張牌前不能胡別人打的牌（自摸不受影響）；放過時會提示，過水中沒有「胡」按鈕，教練欄也會說明。
- 保留八墩（預設開啟）：剩 16 張就流局、莊家連莊；牌桌顯示「可摸 N 張」；海底撈月／河底撈魚改為保留牌前的最後一張。
- 出牌口訣：效率完全相同時，教練先推薦客風（不是門風、圈風，碰了沒台），再是孤張么九、中張；同一級時先打下家打過的牌（盯下家）、再打場上已見多的熟張，並在解說中說明原因。打法比較的每一列標示「生張」或「熟 N」。
- 吃牌提醒：開局幾圈、門清時首選是吃，會提醒吃了就失去門清與門清自摸的台數。
- 教學關卡新增：過水與保留八墩、出牌順序口訣、五搭原理、摸切手切空切、熟張生張與盯下家、清一色混一色訊號，以及 6 題讀牌練習題。
- 一將存檔：莊家、圈風、連莊與分數存在本機，重新開頁接著打；牌局覆盤新增「歷史牌局」（最近 30 局的結果、台數、得失分與失誤）。
- 手機轉向時重新排牌堆位置；橫放時攤牌縮小。
- `node rules.test.cjs`、`node ui-v21.test.cjs` 驗證以上功能。

## v2.0 更新：一將多局、三種難度、教學關卡與何切
- 一將多局：莊家胡牌或流局連莊（連 n 拉 n 另加 2n 台），否則下莊；莊家回到起莊者時換圈風（東風圈 → 南風圈……）。牌桌左上顯示「東風南局・連1」，各家名牌顯示累計分數。
- 台數沿用 v1.6 北部台算法，改為依實際莊家、門風、圈風與連莊計算；結算依「底＋台×每台」（⚙ 可選 50/20、100/20、300/100），自摸三家付、閒家自摸時莊家那份另加。
- 開局：每局由莊家擲三顆骰子，提示從哪家牌牆開門；按 ↻ 開始新的一將時先抓位（隨機座位，抽到東的人當莊，可在 ⚙ 關閉）。第一次開頁仍由你當東家莊家，直接開打。
- 電腦三種難度（⚙）：初級只看進聽數、三成機率亂打、能吃碰就吃碰；中級比較進聽數與有效牌；高級依公開資訊（攤牌組數、牌牆剩餘、後期連打中張）判斷對手是否接近聽牌，自己還遠時改打最安全的牌（棄胡），接近時在效率相近的牌中挑安全的。
- 教練即時提示可開可關（教練欄右上「提示：開／關」或 ⚙）；關閉時按「看提示」可臨時看一次。
- 打錯提醒：出牌比教練首選退一步，或少 4 張以上有效牌時，跳出「這張打掉損失了 N 張進張」；覆盤標記為關鍵失誤。
- 牌局覆盤新增「逐手回放」：每一手的手牌快照、你打的牌（紅框）與教練首選（綠框）、當時打法比較與牌河；可「只看關鍵失誤」。
- 危險度顯示（⚙，進階）：手牌右上角圓點。沒人看起來接近聽牌時一律綠；有威脅的對手還能用這張胡的組合 1–3 種為黃、4 種以上為紅。依可見牌推算，不是放槍機率。
- 新手學堂改為五個階段：0 入門（原開局互動教學）、1 基礎（吃碰槓時機、聽牌型、算台）、2 牌效率、3 看牌面、4 攻守判斷。每階段有講解與練習題：聽哪些牌、算台、何切（牌效率）、防守何切、攻守情境題；答對 5 題通過。
- 學習進度（本機瀏覽器）：各階段答題數、實戰局數、胡牌、自摸、放槍、關鍵失誤與累計分數。
- 手機直放時提示建議橫放；橫放的矮螢幕會縮小牌架與手牌，整桌放進一個畫面。
- `node scoring.test.cjs`、`node ai-levels.test.cjs`、`node quiz.test.cjs`、`node ui-v2.test.cjs` 驗證以上功能。

## 選牌問教練
出牌階段選任何一張牌，教練會比較它和排名第一選擇的進聽數、可改善牌張數。
可按「打我選的這張，可以嗎？」或輸入「打白板可以嗎」「打3萬為什麼不好」「這張可以嗎」「147是什麼」。
目前是本機規則問答，支援選牌比較、吃碰槓回應與指定口訣問題，不是通用聊天；不呼叫外部AI服務。
v0.8 每項出牌顯示各種有效牌的未見張數，合計與原推薦一致；剛打出的牌不會被誤算回未見牌。
在回應階段可問「吃好嗎」「碰好嗎」「槓好嗎」，依實際可用動作解釋；暗槓與加槓也可詢問，但不預測未知補牌。提問不會代替你執行動作。

## 目前支援
- 144 張實際牌組：34 種一般牌各四張、八張花各一張；洗牌、配牌、從牌尾補花。

- 吃（僅上家，可選不同順子）、碰、明槓、暗槓、加槓。吃碰後直接出牌，槓後從牌尾補牌。

- 電腦會比較吃碰槓與略過，出牌優先減少進聽數，其次增加有效牌；能胡先胡。
- 教練顯示「一進聽、兩進聽、已聽牌」，即時計算候選出牌與有幫助的牌。
- 有人出牌可吃碰時，比較吃碰前後進聽數並提醒攤牌取捨。只使用自己手牌、牌河、公開攤牌，不偷看對手暗槓或牌牆。
- 四家牌河、攤牌、補花與出牌／吃碰槓胡紀錄。
- 十節學堂：認牌、抓位、擲骰、數墩、配牌與門牌、補花、吃碰槓、一進聽、三面聽、牌河與剩餘張數。
- 抓位可抽蓋牌，擲骰可選牌牆，數墩需點正確位置，配牌可按步完成；答错會解釋原因。

## 示範桌規與限制
教學先指定東位，抽風牌入座，東位起莊；三骰從莊家逆時針數人，從選中牌牆主人右側數過點數墩，下一墩開始取牌。十八點接到下一面牌牆。
每輪四家各取四張，共四輪，莊家再拿一張門牌。教學與實戰快速配牌分開，抽位結果不改變實戰固定東家。
實戰為便於練習，從莊家取第十七張牌之前開始；牌牆用盡流局。
尚無過水、最低台門檻、計台、特殊牌型、保留尾墩或防守風險分析。已支援加槓搶胡；覆盤涵蓋本局出牌與吃碰槓決策，尚無跨局儲存與回放。
教練所列剩餘張數包含未看見的對手手牌，不是牌牆真實張數；幾進聽不是保證再摸幾次就能聽。
