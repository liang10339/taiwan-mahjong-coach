# 牌桌教練｜台灣麻將練習

第一版 PWA 原型：以台灣 16 張麻將為基礎，提供更接近實體牌桌的響應式牌桌、新手學堂與基礎教練提示。

## 目前功能

- 響應式手機／電腦牌桌（17 張手牌依寬度縮放）
- 教練實戰、新手學堂、牌局覆盤三個主要入口
- 完整 144 張牌牆：萬、筒、條各 36 張、字牌 28 張、花牌 8 張，洗牌後發牌
- 你坐東家（莊家），開門 17 張先出牌；輪序依逆時針：東 → 南（下家）→ 西（對家）→ 北（上家）
- 摸到花牌自動亮出並從牌尾補牌
- 牌牆摸到只剩留牌 16 張即流局
- 胡牌判定：五組加一對，可自摸，也可胡別家打出的牌（可選擇「過」）
- 三位初級電腦依向聽數與進張出牌，也會自摸或胡牌
- 教練提示即時計算向聽數與有效進張，比較每一種打法
- 牌局結束後，覆盤會列出每一巡你的出牌與教練首選的差異
- 五步驟互動式新手課程
- PWA manifest、圖示與 service worker 離線快取（更新版本時清除舊快取）

尚未支援：吃、碰、槓與台數計算。

## 開發方向

下一階段會把規則核心抽成獨立的 TypeScript 規則引擎，並加入固定亂數種子、吃碰槓、台數計算與更完整的覆盤。

## 啟動

可直接用瀏覽器開啟 `index.html`。若要測試 PWA 離線快取，請使用本機 HTTP server，例如 `npx serve .`。
