# 牌桌教練｜台灣麻將練習

第一版 PWA 原型：以台灣 16 張麻將為基礎，提供更接近實體牌桌的響應式牌桌、新手學堂與基礎教練提示。

## 目前功能

- 響應式手機／電腦牌桌
- 教練實戰、 新手學堂、牌局覆盤三個主要入口
- 手牌選取、整理、摸牌與重新開始
- 基礎向聽／有效進張教練提示介面
- PWA manifest 與 service worker 離線快取
- 有限牌牆：摸牌後必須出牌，牌牆摸完後流局
- 五步驟互動式新手課程
- 牌河、座位、局風與牌牆剩餘張數顯示

## 開發方向

下一階段會把目前的展示資料替換成獨立的 TypeScript 規則引擎：固定亂數種子、完整輪序、吃碰槓胡、胡牌判定、動作紀錄與覆盤。

## 啟動

可直接用瀏覽器開啟 `index.html`。若要測試 PWA 離線快取，請使用本機 HTTP server，例如 `npx serve .`。
