# 牌桌教練 v0.7
台灣 16 張的單機教練練習。仍採下列簡化桌規，並非完整比賽規則。

## 開啟
在本資料夾執行 `python -m http.server 4176 --bind 127.0.0.1`，開啟 http://localhost:4176 。
右上角顯示「教練練習 v0.7」。

## 選牌問教練
出牌階段選任何一張牌，教練會比較它和排名第一選擇的進聽數、可改善牌張數。
可按「打我選的這張，可以嗎？」或輸入「打白板可以嗎」「打3萬為什麼不好」「這張可以嗎」「147是什麼」。
目前是本機規則問答，僅支援選牌比較與指定口訣問題，不是通用聊天；不呼叫外部AI服務。
同分選擇會標示並列。只列前三名不代表其他牌錯誤，並列也不代表台數與防守價值相同。
已用使用者截圖牌型重現白板：三進聽、19張，與7萬、1筒、4筒並列。

## 三面聽課程
學堂新增第9、10節：同花色23456等147、34567等258、45678等369，按範例可看拆組。
前提為其他部分完成三組加一對（含攤牌）；不是單獨留147比較容易胡，也不是安全牌保證。
同花色23456等待147最多11張：4已在手上一張；還須扣除其他可見牌。實戰會提示手中五連張，但不會僅憑局部形狀宣稱整手已聽牌。
參考：[三面聽牌型說明](https://chejohntravel.com/麻將三面聽牌/)。各範例另用胡牌引擎驗算三種花色。

## 目前支援
- 144 張實際牌組：34 種一般牌各四張、八張花各一張；洗牌、配牌、從牌尾補花。
- 玩家摸牌 → 選牌 → 確認出牌；嚴格回合限制與重開取消計時器。
- 吃（僅上家，可選不同順子）、碰、明槓、暗槓、加槓。吃碰後直接出牌，槓後從牌尾補牌。
- 五組加一對的自摸與放槍胡，包含攤牌組數。胡優先於碰槓，碰槓優先於吃；多人胡採從出牌者下家方向最近一家。
- 電腦会胡與碰，出牌優先減少進聽數；目前不主動吃或槓。
- 教練顯示「一進聽、兩進聽、已聽牌」，即時計算候選出牌與有幫助的牌。
- 有人出牌可吃碰時，比較吃碰前後進聽數並提醒攤牌取捨。只使用自己手牌、牌河、公開攤牌，不偷看對手暗槓或牌牆。
- 四家牌河、攤牌、補花與出牌／吃碰槓胡紀錄。
- 十節學堂：認牌、抓位、擲骰、數墩、配牌與門牌、補花、吃碰槓、一進聽、三面聽、牌河與剩餘張數。
- 抓位可抽蓋牌，擲骰可選牌牆，數墩需點正確位置，配牌可按步完成；答错會解釋原因。

## 示範桌規與限制
教學先指定東位，抽風牌入座，東位起莊；三骰從莊家逆時針數人，從選中牌牆主人右側數過點數墩，下一墩開始取牌。十八點接到下一面牌牆。
每輪四家各取四張，共四輪，莊家再拿一張門牌。教學與實戰快速配牌分開，抽位結果不改變實戰固定東家。
實戰為便於練習，從莊家取第十七張牌之前開始；牌牆用盡流局。
尚無搶槓、過水、最低台門檻、計台、特殊牌型、保留尾墩、完整逐手覆盤或防守風險分析。加槓直接補牌，不開搶槓回應。
教練所列剩餘張數包含未看見的對手手牌，不是牌牆真實張數；幾進聽不是保證再摸幾次就能聽。
