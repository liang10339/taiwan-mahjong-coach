# 牌桌教練 v2.8
台灣 16 張的單機教練練習（PWA，可離線、可安裝到手機主畫面）。仍採下列簡化桌規，並非完整比賽規則。

## 開啟
- 需要 [Node.js](https://nodejs.org/) 20 以上。第一次先執行 `npm install`（安裝格式與型別檢查工具）。
- `npm start`，開啟 http://localhost:4176 。右上角顯示「教練練習 v2.8」。
- 沒有 Node.js 時也可以：`python -m http.server 4176 --bind 127.0.0.1`。
- 發布後的網址：main 更新時會自動部署到 GitHub Pages（見下方「開發」）。

## 開發
| 指令 | 用途 |
|---|---|
| `npm start` | 本機伺服器 http://localhost:4176 |
| `npm test` | 平行執行 `tests/` 全部測試（約 15 秒） |
| `npm run typecheck` | TypeScript 檢查 `src/` 的 JavaScript（依 JSDoc 型別） |
| `npm run format` | 用 Prettier 統一排版 |
| `npm run check` | 格式＋型別＋測試，送 PR 前跑一次 |
| `npm run bump` | 改版時更新離線快取版本（sw.js 與 index.html 的 `?v=` 一起改） |

- 程式架構、資料流與日後擴充的方式見 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。
- 每個 PR 都會由 GitHub Actions 自動跑格式、型別與測試（`.github/workflows/ci.yml`）。
- main 更新後自動發布到 GitHub Pages（`.github/workflows/pages.yml`）。第一次使用前，到 GitHub 專案 **Settings → Pages**，把 **Source** 設為 **GitHub Actions**。

## v2.8 更新：量得準、台數與守到底、單一決策核心、實際取墩、實戰記錄、技能練習、對手風格
- **評估量得準**：進聽數計算快約十倍（30 萬手隨機牌和舊版逐手比對完全相同）。`scripts/evaluate-coach.cjs` 改成公平對照——同一副牌讓「照教練打」輪流坐四個座位、各和「只看效率」比，依 CPU 數平行、結果逐副存檔可接續、可和舊版逐副相減。32000 局約 6 分鐘（v2.7 的 8000 局約 67 分鐘）。CI 另有固定牌組的守門測試。
- **台數進入決策**：教練估計「這手胡了大約幾台」（聽牌時逐張聽牌實際計台；還沒聽看門清、字牌刻／對、花、一色）。速度差不多時選台數高的，標題寫「做台數：打 X」；吃碰會算進少掉的門清台，進張變好但台數損失更大時建議略過。
- **守到底**：之後幾巡的放槍代價也算進去——繼續攻每巡都要冒險，改守可以先打手上的安全牌，安全牌用完才危險。效率首選剛好也最安全時，先打它、之後準備守。
- **單一決策核心**：高級電腦改用和教練同一套判斷；教練欄原本另跑一套模擬、可能和標題建議不一致，改成直接列出教練選牌用的「攻守期望值表」（胡牌率、胡了約幾台、放槍率、期望）。舊的防守組合排除（defense.js）與模擬（value.js）移除。
- **實際取墩配牌**：從莊家起每人每次拿兩墩（4 張）、拿四輪，配完再依序補花；開局動畫照引擎實際的配牌事件播放（你的牌翻開）。舊牌譜、舊分享連結照舊配牌程序重播，結果和以前完全相同。
- **實戰記錄**：「牌局覆盤 → 實戰記錄」可以把在實體牌桌或其他地方打的牌一步步點進來（只記你看得到的事，別家摸什麼不用記），打完由同一個教練逐手覆盤；有撤銷、草稿自動保存、不合理的一步會指出原因。格式見 [docs/RECORD_FORMAT.md](docs/RECORD_FORMAT.md)。
- **技能練習**：每手出牌標上考的技能（孤張順序、搭子取捨、聽牌選擇、台數取捨、防守判斷、吃碰判斷），成長報告列出各技能和教練一致的比例與熟練狀態，指出最該練的一項；錯題本可以「只練某一種技能」。
- **對手風格**：高級電腦可選速攻、保守、大牌或混合（三家各一種）。各風格另外自戰校準聽牌模型，教練知道對手是哪種電腦時用那一種。
- **結果（誠實版）**：v2.8 對「只看效率」，混合對手 16000 局對照每局 −0.012 ± 0.049 台；對三家速攻 −0.06 ± 0.10、三家保守 +0.08 ± 0.10、三家大牌 −0.01 ± 0.09 台（各 4000 局）——都在誤差內。放槍在每種對手都少約 3.5–4 個百分點（例如 15.3% 對 18.8%），胡牌約少 1–2 個百分點。台數與守到底各自和前一版逐副比較是 +0.035 ± 0.028 與 +0.001 ± 0.007 台。結論：教練穩定地少放槍、會解釋原因，但還不能說照著打會贏更多；這些數字只代表對本程式的電腦，對真人沒有資料（詳見 [docs/CALIBRATION.md](docs/CALIBRATION.md)）。

## v2.7 更新：牌譜、接續牌局、研究方法的預測模型
- **牌局自動保存、可以接續**：每個動作後自動保存；重新整理或網站更新後，開始畫面會出現「接續上一局」，回到原本的局面（覆盤紀錄一起接回）。
- **完整牌譜**：每局存成「洗牌種子＋桌規＋每位玩家的動作」，有格式與發牌程序版本（格式說明見 [docs/RECORD_FORMAT.md](docs/RECORD_FORMAT.md)）。覆盤分頁的「牌譜」可以逐步回放最近 30 局（四家手牌、攤牌、牌河）、下載、匯入別人的牌譜；局後卡片也能下載這局。格式預留了日後「實戰記錄」使用的單一玩家視角（v2.8 已實作）。
- **引擎紀錄吃牌用了哪兩張**：同一張牌有兩三種吃法時，牌譜也能完整重現。
- **聽牌與放槍改用邏輯迴歸**：參考台灣麻將聽牌預測與防守研究的特徵（巡目、吃碰數、摸切節奏、最近手切的中張；對手打過這張或旁邊的牌、打這一門的比例等「非需求度」），驗證局上聽牌預測誤差少 6.4%、放槍預測誤差少 5.0%。「他自己打過這張」是最強的線索，教練會講出來。4000 局同牌對照：放槍從 20.0% 降到 14.9%，胡牌率略少（25.3% 對 26.1%），每局得失 +0.06 ± 0.10 台，還不能說更會贏錢（見校準報告）。
- **修正**：牌效率並列時，解說不再把摸切寫成「最好的打法」而和標題建議矛盾。

## v2.6 更新：第三階段——建議前後一致、防守 2.0、攻守期望值
- **建議前後一致**：新增決策核心（`src/core/advisor.js`），教練標題、吃碰卡片、場況判斷、覆盤、錯題本、問教練全部讀同一個決定。吃碰卡片上的「吃後打 X」是把吃碰後的局面真的做出來再問同一個決策，照做後教練一定也建議打 X（以前約 29% 會改口）。
- **對手模型**：用攤牌數、打了幾張、連續摸切估計三家「聽牌的機率」，並估計他胡了大約幾台（莊家連莊、做一色、有台的字牌刻子）。
- **防守 2.0**：每張牌算出放槍機率並寫出理由——四張都見的字牌（一定安全）；電腦對手手牌沒換過期間放過的牌（依「電腦有胡必胡」的模型推估，不是真人牌桌的保證；教練不讀對手私密的過水狀態）；壁（順子等不到）、字牌見張數、中張／么九；他一直在打的那門（較安全）。「手切附近」「做一色的那門」這類教學說法會先經過自戰統計檢驗，對本程式的電腦看不出差別時就不列為理由（見校準報告）。手牌上的危險度標記、「放槍風險與攻守比較」卡、覆盤都用這套。
- **攻守期望值**：每張候選牌算「之後胡牌的機率 × 胡牌收入 − 放槍機率 × 對方台數（含底）」。效率首選仍划算就照打；改打安全牌明顯划算時，標題會寫「建議先守」或「攻守兼顧」並列出兩邊的數字。有人很可能聽牌、吃碰後仍差兩步以上時不建議吃碰。
- **實際打起來比較好**：同一副牌對照 800 局，照教練打與只看牌效率相比，胡牌率不變（27.1% 對 26.9%），放槍從 18.3% 降到 15.3%（`scripts/evaluate-coach.cjs`，見校準報告）。
- **數字有依據**：`npm run calibrate` 讓電腦自戰幾千局（知道每家真正手牌）統計上述機率，並在沒拿來統計的驗證局上報告準確度，見 [docs/CALIBRATION.md](docs/CALIBRATION.md)。
- **教學對齊**：新手學堂新增「放過的牌：模型推估，不是安全保證」「過水：知道規則不等於知道暗牌」「手切的牌附近與不做的那門」「放槍機率怎麼估」「用期望值決定攻守」「吃碰前先踩煞車」；防守練習題改用同一套放槍機率出題與講解。你放槍的那一手會自動存進錯題本，題目是「打哪張最安全」。

## v2.5 更新：教練會看場況
- **場況判斷**放在教練欄最上面：依局勢標出「做牌／進攻／攻守兼顧／先守」，一句話講這手的重點，再列最重要的兩三點；別家回合與摸牌前也會提示。
- 看的是整張桌子：三家的聽牌訊號（攤牌數、連續摸切、連打中張、做一色）、**每家「放過」的牌**（他手牌沒換過的期間摸切或沒胡的牌，當時沒胡、現在也不會胡）、牌牆剩幾張（你大約還能摸幾次）、死掉或快死的搭子、聽牌剩幾張、這手值不值錢（一色、有台的字牌對子、碰碰胡、莊家連莊）、下家吃過的花色。
- 有人很可能聽牌而你還差很遠、或牌牆快摸完時，標題會改成「建議先守：打 X」，並說明為什麼安全；純牌效率的首選仍列在旁邊。
- 同樣的話幾手內不重複（重要警告例外）；原本每手都一樣的牌效率解說收進「牌效率細節」，攻守取捨與讀牌筆記平常也收起來，需要時才展開。

## v2.4 更新：鑑別度核心——期望值、錯題本、成長報告、公平性證明
- **胡牌率×台數的期望值教練**：出牌時比較每張候選牌「多快胡、胡多大」。用蒙地卡羅模擬（每張牌 400 次，在背景執行緒跑，約 1.5 秒、不卡畫面）估出胡牌率、平均台數與期望台數；最快聽牌和期望值最高的打法不同時會特別提醒。別家胡牌的機率依 400 局電腦自戰實測，胡牌率偏保守（約為實戰的一半），適合比較候選牌之間的高低。⚙ 可關閉。
- **錯題本（間隔重複）**：實戰的關鍵失誤自動存成「這手要打哪張？」題目。答錯 10 分鐘後重考，答對依序隔 1、3、7、21 天再出，第五次答對算熟練；評分用教練同一套算法，並列最佳都算對。「牌局覆盤」分頁上的數字是今天要複習的題數。
- **成長報告**：與教練一致率、每 100 手關鍵失誤、胡牌率、放槍率，最近 10 局和之前 10 局比較；一致率趨勢圖、序盤／中盤／終盤各自的一致率，以及下一步該練什麼。歷史改存最近 100 局。
- **公平性證明**：開局在牌桌中央公布「牌牆指紋」，一局結束後公開洗牌種子、攤開三家手牌與接下來的牌牆，當場用種子重洗驗證指紋相同、牌牆沒被抽換。「複製這副牌的連結」讓朋友打同一副牌，「同一副牌再打一次」可以自己重打比較。

## v2.3 更新：打底——可維護性、效能、開局模式
- **開始畫面與開局模式**：開頁先選「直接開始」或「完整開局」。完整開局依序演示抓位（親手抽風牌）→ 擲骰（從莊家逆時針數點數）→ 開門（在 18 墩牌牆上數墩）→ 配牌（四輪、每次兩墩）→ 補花，用的是這一局真實的骰子、開門位置與花牌；每一步都能跳過。選擇會記住，⚙ 也能改。
- **修正第一局沒有聲音**：瀏覽器規定使用者先點一下才能出聲，現在第一次點擊或按鍵就解鎖音效與報牌；語音清單較晚載入的瀏覽器（例如 Windows 的 Chrome）會先排隊、載入後補唸。
- **速度**：進聽數計算改為逐門快取（結果和原本完全相同，快約 8 倍），電腦評估槓牌時不再卡頓（最久約 0.9 秒 → 30 毫秒內）；牌河改成只補新打出的牌，平均每次重畫約 26 毫秒 → 3 毫秒。
- **修正**：手牌下方的狀態只說明你自己該做什麼（別家回合不再顯示「請出牌」）；手機寬度 320px 以上都不會左右晃動。
- **程式整理**：檔案分成 `src/core`（規則、計台、教練、AI，不碰畫面）、`src/ui`、`styles`、`tests`；原本 543 行的 app.js 依功能拆成 9 個檔案；全部程式用 Prettier 排版；加上 TypeScript 型別檢查、牌局資料模型說明（`src/types/game.d.ts`）、自動測試與自動部署。

## v2.2 更新：用動作看出摸切、手切、空切；隨時整理手牌
- 出牌改成從牌實際所在的位置飛進牌河，不再用文字標示：
  - 摸切：剛摸進、放在最右邊隔開的那張直接丟出，其他牌不動。
  - 手切：從牌列中間先抽起一張再飛出，後面的牌補位，剛摸的那張滑進手牌。
  - 空切：看起來和手切一樣（這正是空切的用意）。
- 四家都一樣：電腦摸牌時，新牌從上方落在牌架最右邊並隔開，接著出牌就看得出是摸切還是手切（左右兩家的牌架依旋轉方向換算動作）。
- 拿掉牌河的「摸／空」字樣、圖例與座位上的「連續摸切」文字；讀牌筆記仍會整理訊號。灰底輔助標示改為 ⚙ 選項、預設關閉。
- 電腦每步間隔放慢到 0.7 秒，看得清楚動作；系統開啟「減少動態效果」時不播動畫。
- 「整理手牌」隨時都能按（別人出牌、吃碰回應時也可以），排序有滑動動畫；剛摸進還沒打的那張仍留在最右邊。

## v2.1 更新：摸切／手切、過水、保留八墩、讀牌與口訣
參考網路上的台灣麻將教學（見文末「參考資料」），比對後補上下列規則與教練觀念：
- 摸切／手切／空切：引擎記錄每張出牌方式（v2.2 起改用出牌動作呈現）。自己剛摸進的牌放在最右邊、上方標「摸」，「整理手牌」不會把它排進去。點最右邊那張是摸切；點手中另一張相同的牌就是空切（別人看起來是手切，只有你自己的牌河標「空」）。電腦要打剛摸進的牌時一律摸切。
- 讀牌：各家名牌顯示「連續摸切 N」；教練欄新增「讀牌筆記」，依攤牌、連續摸切、最近手切的牌、一直打哪門、攤牌是否全同一花色（清一色／混一色訊號）整理三家的訊號。高級電腦與危險度也使用這些訊號：連續摸切三巡以上視為可能聽牌、四巡以上視為很可能聽牌；攤牌全同一花色時，該門與字牌危險度加倍。
- 過水（預設開啟）：放過胡牌後，在自己打出一張牌前不能胡別人打的牌（自摸不受影響）；放過時會提示，過水中沒有「胡」按鈕，教練欄也會說明。
- 保留八墩（預設開啟）：剩 16 張就流局、莊家連莊；牌桌顯示「可摸 N 張」；海底撈月／河底撈魚改為保留牌前的最後一張。
- 出牌口訣：效率完全相同時，教練先推薦客風（不是門風、圈風，碰了沒台），再是孤張么九、中張；同一級時先打下家打過的牌（盯下家）、再打場上已見多的熟張，並在解說中說明原因。打法比較的每一列標示「生張」或「熟 N」。
- 吃牌提醒：開局幾圈、門清時首選是吃，會提醒吃了就失去門清與門清自摸的台數。
- 教學關卡新增：過水與保留八墩、出牌順序口訣、五搭原理、摸切手切空切、熟張生張與盯下家、清一色混一色訊號，以及 6 題讀牌練習題。
- 一將存檔：莊家、圈風、連莊與分數存在本機，重新開頁接著打；牌局覆盤新增「歷史牌局」（最近 30 局的結果、台數、得失分與失誤）。
- 手機轉向時重新排牌堆位置；橫放時攤牌縮小。
