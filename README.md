# 牌桌教練 v0.5
目前是台灣 16 張的「摸打練習」，不是完整台灣麻將規則。

## 使用
在本資料夾執行 `python -m http.server 4176 --bind 127.0.0.1`，開啟 http://localhost:4176 。
按摸牌 → 點選手牌 → 確認出牌 → 等待三家電腦。
畫面右上角顯示「摸打練習 v0.5」代表新版已載入。

## 已實作
- 34 種基本牌每種四張，8 張花牌各一張，共 144 張。實際洗牌、配牌、補花與有限牌牆。
- 固定東家玩家；為方便練習，以莊家尚未取第十七張牌開始。
- 嚴格回合檢查；選牌需確認；重新開始會取消電腦排程。
- 玩家與電腦自摸檢查：五組加一對。不接受跨花色順子。
- 教練從目前手牌計算出牌後向聽與有效進張；數量僅扣除可見牌，不偷看對手或牌牆。
- 各家牌河、補花、出牌文字紀錄及五頁入門說明。
- 網路優先快取，只讀本版本快取，更新後自動重新載入。
